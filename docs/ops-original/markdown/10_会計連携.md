## 3. 例外処理と判断基準

> [!WARNING]
> 以下の例外処理は現時点でフロー図から読み取れた内容です。**SME（山田様・澤田様）へのヒアリングにて追加・修正が必要です。**

| # | 例外事象 | 判断基準 | 対応手順 | エスカレーション先 |
|---|---------|---------|---------|-----------------|
| E-1 | CSVデータ連携エラー | 取込時にエラーが発生 | ①エラー内容確認 ②CSV形式・文字コード確認 ③マスタ設定確認 ④手動修正・再取込 | 経理リーダー |
| E-2 | 勘定科目マスタの不整合 | 新規勘定科目が未登録 | ①勘定科目入力で追加登録 ②仕訳変換マスタも更新 | 経理 |
| E-3 | 仕訳データの不一致 | アラジンオフィスの計上データと会計システムの仕訳が不一致 | ①差異原因の特定 ②仕訳変換マスタの確認 ③手動で修正仕訳入力 | 経理リーダー |
| E-4 | 振替伝票の自動作成失敗 | 取込後に振替伝票が生成されない | ①データ内容の確認 ②会計システムの設定確認 ③手動で振替伝票作成 | 経理リーダー |

## 4. ミス防止チェックリスト

### 4.1 マスタ管理チェック

- [ ] 勘定科目マスタが最新の状態に更新されているか
- [ ] 仕訳変換マスタ（売上/仕入/入金/出金）が正しく設定されているか
- [ ] 新規取引先・新規商品に対応するマスタが登録されているか

### 4.2 データ出力チェック

- [ ] 仕訳データ出力（売上）が正常に完了したか
- [ ] 仕訳データ出力（仕入）が正常に完了したか
- [ ] 仕訳データ出力（入金）が正常に完了したか
- [ ] 仕訳データ出力（出金）が正常に完了したか
- [ ] CSVファイルが正しい形式で出力されているか

### 4.3 データ連携チェック

- [ ] 売上データ連携が正常に完了したか
- [ ] 仕入データ連携が正常に完了したか
- [ ] 入金データ連携が正常に完了したか
- [ ] 出金データ連携が正常に完了したか
- [ ] 会計管理システムでのデータ取込が完了したか
- [ ] 振替伝票が正常に自動作成されたか

### 4.4 経費関連チェック

- [ ] 交通費等の経費は会計システムで手入力されているか
