## 2. 操作手順

> [!NOTE]
> 買継取引は「仕入先→得意先」へ商品を直接配送するフローです。自社倉庫を経由しません。
> 配送形態によって3パターンに分岐します。

### 2.1 パターンA：通常フロー（直送：国内仕入先）

**対象ページ**: Page 2
**関与者**: 得意先 ← 営業 ← 営業事務（貿易事務兼任） → 倉庫 → 仕入先倉庫 → 仕入先（国内）

```
得意先         営業              営業事務           倉庫    仕入先倉庫  仕入先
  │──引合──→│                    │               │        │        │
  │←─回答──│ メール又は口頭     │               │        │        │
  │←見積書─│ 見積(Excel)        │               │        │        │
  │         │                    │メールで発注処理│        │        │
  │──注文──→│ 注文書            │──発注─────────→│        │        │→
  │         │ 受発注同時         │               │        │        │
  │         │ 計上入力           │               │        │        │
  │         │     ↓ 受注発注書   │               │        │        │
  │         │     基本は都度依頼  │               │        │        │
  │         │                    │      ↓        │        │        │
  │←荷渡指図書──────────────────│ 荷渡指図書     │売仕入同時│      │        │
  │         │                    │           計上入力│     │        │
  │         │                    │               │        │ →商品→│
  │←────────────商品──────────────│───────────────│────────│←商品←│
```

#### ステップ一覧

| Step | 担当 | 操作内容 | 使用システム/ツール | 出力帳票 |
|------|------|---------|-------------------|----------|
| 1 | 営業 | 得意先からの引合を受け、メール又は口頭で回答 | — | — |
| 2 | 営業 | 見積書をExcelで作成し、得意先へ提出 | Excel | 見積書 |
| 3 | 営業事務 | 仕入先へメールで発注処理を実施 | メール | — |
| 4 | 営業 | 得意先から注文書を受領 | — | 注文書 |
| 5 | 営業 | アラジンオフィスで「受発注同時計上入力」を実行 | アラジンオフィス | 受注発注書 |
| 6 | 営業事務 | 倉庫へ配送依頼（基本は都度依頼） | — | — |
| 7 | 営業事務 | 「売仕入同時計上入力」を実行 | アラジンオフィス | 荷渡指図書 |
| 8 | 営業事務 | 荷渡指図書を得意先へ送付 | — | 荷渡指図書 |
| 9 | 仕入先 | 仕入先倉庫から商品を出荷 | — | — |
| 10 | 倉庫 | 商品を得意先へ配送 | — | — |

### 2.2 パターンB：直送（仕入先が輸入をしている場合）

**対象ページ**: Page 3
**関与者**: 得意先 ← 営業 ← 営業事務（貿易事務兼任） → 倉庫 → 港 → 仕入先（国内）

> [!IMPORTANT]
> 仕入先が輸入をしているパターンでは、**船積スケジュール管理**と**動静確認**が追加で必要になります。

#### ステップ一覧

| Step | 担当 | 操作内容 | 使用システム/ツール | 出力帳票 |
|------|------|---------|-------------------|----------|
| 1 | 営業 | 得意先からの引合を受け、メール又は口頭で回答 | — | — |
| 2 | 営業 | 見積書をExcelで作成し、得意先へ提出 | Excel | 見積書 |
| 3 | 営業事務 | 仕入先へメールで発注処理を実施 | メール | — |
| 4 | 営業 | 得意先から注文書を受領 | — | 注文書 |
| 5 | 営業 | アラジンオフィスで「受発注同時計上入力」を実行 | アラジンオフィス | 受注発注書 |
| 6 | 営業事務 | 受注発注書を受領し「発注計上入力」を実行 | アラジンオフィス | — |
| 7 | 営業 | 仕入先から船積スケジュールを受領 | — | 船積スケジュール |
| 8 | 営業事務 | 船積スケジュールをもとに「入荷予定入力」を実行 | アラジンオフィス | — |
| 9 | 営業事務 | 動静確認を実施（船会社のHP等で確認） | 船会社HP等 | — |
| 10 | 営業事務 | 船社/船名、ETD、ETA、ブッキング番号等を追記 | アラジンオフィス | — |
| 11 | 営業事務 | B/L No. を追記 | アラジンオフィス | — |
| 12 | 倉庫 | パッキングリストを受領 | — | パッキングリスト |
| 13 | 営業事務 | 「入荷予定入力」を更新 | アラジンオフィス | — |
| 14 | 営業事務 | 「仕入計上入力」を実行 | アラジンオフィス | — |
| 15 | 倉庫 | ディスパッチ（D/O）を受領・処理 | — | ディスパッチ(D/O) |
| 16 | 営業事務 | 「売仕入同時計上入力」を実行し荷渡指図書を発行 | アラジンオフィス | 荷渡指図書 |
| 17 | 営業事務 | 荷渡指図書・ディスパッチ(D/O)を得意先へ送付 | — | 荷渡指図書, D/O |
| 18 | 倉庫 | コンテナから商品を出荷し得意先へ配送 | — | — |

> [!TIP]
> **動静確認のポイント**:
> - 入船するまで何度も確認すること
> - 遅延がある際は入船予定表を更新し、スケジュール表を得意先へ再送
> - 得意先+商品によっては入船予定表も管理している

## 3. 例外処理と判断基準

> [!WARNING]
> 以下の例外処理は現時点でフロー図から読み取れた内容です。**SME（山田様・澤田様）へのヒアリングにて追加・修正が必要です。**

### 3.1 例外一覧

| # | 例外事象 | 判断基準 | 対応手順 | エスカレーション先 |
|---|---------|---------|---------|-----------------|
| E-1 | 仕入先からの納期遅延 | 得意先の希望納期に間に合わない場合 | ①営業が得意先へ遅延連絡 ②代替品の提案を検討 | 営業マネージャー |
| E-2 | 船積遅延（パターンB） | ETAが当初予定より遅延 | ①入船予定表を更新 ②スケジュール表を得意先へ再送 ③船会社HPで継続確認 | 営業事務リーダー |
| E-3 | 注文内容と見積内容の不一致 | 品名・数量・単価に差異がある場合 | ①営業が得意先へ確認 ②修正注文書の再取得 | 営業 |
| E-4 | パッキングリストと実荷姿の不一致 | 数量・重量に差異がある場合 | ①倉庫が営業事務へ報告 ②仕入先へ確認・クレーム対応 | 営業事務リーダー |
| E-5 | 受発注入力エラー | アラジンオフィスでの入力時にエラー発生 | ①エラー内容を確認 ②マスタ登録漏れの場合はマスタ追加 | システム管理者 |

### 3.2 判断フローチャート

```
注文書受領
  ├── 内容に不備あり？
  │     ├── YES → 営業が得意先へ差し戻し（E-3）
  │     └── NO → 受発注同時計上入力へ
  │
  ├── 仕入先が輸入している？
  │     ├── YES → パターンBフロー（船積管理あり）
  │     └── NO → パターンAフロー（通常）
  │
  └── 自社配送？
        ├── YES → パターンCフロー
        └── NO → 仕入先倉庫経由
```

## 4. ミス防止チェックリスト

### 4.1 受注時チェック

- [ ] 得意先の注文書と見積書の内容（品名・数量・単価・納期）が一致しているか
- [ ] アラジンオフィスの得意先コード・商品コードが正しいか
- [ ] 受発注同時計上入力が正常に完了したか
- [ ] 受注発注書が正しく出力されたか

### 4.2 発注・仕入時チェック

- [ ] 仕入先へのメール発注内容に誤りがないか
- [ ] 発注計上入力が完了しているか（パターンB）
- [ ] 船積スケジュールの入荷予定入力が完了しているか（パターンB）
- [ ] B/L No. の追記が漏れていないか（パターンB）
- [ ] パッキングリストの内容と入荷予定の整合性が取れているか（パターンB）

### 4.3 出荷・納品時チェック

- [ ] 「売仕入同時計上入力」が正常に完了したか
- [ ] 荷渡指図書が正しく発行・得意先へ送付されたか
- [ ] ディスパッチ(D/O)が得意先へ送付されているか（パターンB）
- [ ] 商品が正しい納品先へ配送されたか
- [ ] 個包装の数量に過不足がないか

### 4.4 全パターン共通チェック

- [ ] アラジンオフィスの計上処理（売上・仕入）がすべて完了しているか
- [ ] 帳票（見積書・注文書・受注発注書・荷渡指図書）の保管が完了しているか
- [ ] 得意先への連絡事項（納期・配送情報等）に漏れがないか
